# Video skill index (source: @xaiwind 〈Codex 爆款视频skill，10个装完百万播放〉, 2026-10-10)

Location: each repo is a regular folder under <SKILLS_DIR>/<repo>/; Claude Code reads them through symlinks at ~/.claude/skills/<skill名> (every bot sharing this machine can read SKILL.md directly).
How to invoke: say the trigger phrase in Claude Code, or type /<skill名>; other bots read the SKILL.md at that path directly and follow the workflow.
Node 22: lives in <YOUR_WORKSPACE>/tools/node22/bin (the system default is still Node 20). For tools that need Node 22, first run `export PATH=<YOUR_WORKSPACE>/tools/node22/bin:$PATH`. hyperframes is wrapped so it uses Node 22 automatically.
Shared dependencies already installed: ffmpeg, uv, Playwright Chromium, Pillow, imageio-ffmpeg, requests, yt-dlp, edge-tts, HyperFrames CLI 0.8.145, Remotion (investigation template).
